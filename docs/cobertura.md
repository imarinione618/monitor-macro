Estados: **verificado** = selector probado contra la API real (1 fila por período) y datos en el store · **no encontrado** = no existe en los 19 endpoints de la API de INDEC · **fuente complementaria** = existe en otra fuente oficial (no INDEC API), no implementado · **disponible, no incorporado** = está en la API pero fuera del registro actual.

Selectores: `{columna: valor}` exactos sobre las filas crudas (ver `src/core/registry/*.ts`). Dimensiones completas de cada endpoint: `docs/catalogo-dimensiones.md`.
